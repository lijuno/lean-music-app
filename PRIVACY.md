# Privacy Policy

Effective: August 27, 2026

lean-music-app is a local, unofficial wrapper for the YouTube Music website.

## Data handled by the app

The app uses Apple's `WKWebView` with persistent website storage. Google and YouTube may store cookies, caches, local storage, account state, preferences, and website-managed media data inside the app's macOS sandbox. That data remains on the user's Mac unless the relevant website transmits it as part of normal website operation.

The app has no developer-operated server, telemetry, analytics, advertising, crash-reporting SDK, account database, JavaScript bridge, or custom YouTube API integration. The developer does not receive Google credentials, listening history, cookies, or other account data through the app.

## Network access

The sandbox grants outbound network access so WebKit can connect directly to Google, YouTube, and links the user explicitly opens. Those services process data under their own terms and privacy policies.

## Retention and deletion

Website data persists so users remain signed in between launches. Choose **Lean Music App → Clear Website Data and Sign Out…** and confirm **Clear Data** to remove all cookies, caches, local storage, and website-managed downloads held by this app. Removing the application alone may not remove its sandbox container.

## Changes

Material changes to this policy will be documented in the repository changelog and included with a new application release.

## Contact

Open a GitHub issue for general privacy questions. Do not include credentials, cookies, account identifiers, or other sensitive information in public issues.
